# MSG-Toy-Store-Dashbord
Retail analytics dashboard revealing top-performing store locations and monthly profit trends using Power BI.


# 📊 MS Toy Store Report — Power BI Dashboard

![Dashboard Screenshot](./images/dashboard-preview.png)

## 📌 Project Overview

An interactive Power BI dashboard built using the **Maven Analytics Toy Store dataset**. The report provides a comprehensive view of sales performance across 50 store locations, tracking revenue, profit, and order volume over an 18-month period.

## 🎯 Business Questions Answered

| Question | Visual Used |
| :--- | :--- |
| How many stores and orders do we have? | KPI Cards |
| Which store locations drive the most orders? | Donut Chart |
| Which locations generate the most revenue? | Bar Chart |
| How does profit trend over time? | Line Chart |

## 📈 Key Metrics

| Metric | Value |
| :--- | :--- |
| Total Stores | 50 |
| Total Orders | 829K |
| Total Revenue | R14.44M |
| Total Profit | R4.01M |

## 💡 Key Insights

- **Downtown** stores are the top revenue drivers (R8M+), followed by Commercial locations
- **Airport** stores have the lowest revenue contribution, suggesting a potential review of store placement or inventory
- **Profit peaks** in early 2023, with notable fluctuations indicating seasonal demand
- Order distribution is fairly balanced across Residential, Commercial, and Airport locations

## 🛠️ Tech Stack

- **Power BI Desktop** — Report building
- **DAX** — Calculated measures (Total Revenue, Total Profit, Order Counts)
- **Power Query** — Data transformation and cleaning

## 🚀 How to Use

1. Download the `.pbix` file from this repository
2. Open in **Power BI Desktop** (free download from Microsoft)
3. Interact with the slicers and visuals to explore the data
